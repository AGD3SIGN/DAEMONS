# Sprite prompts for ChatGPT

Generated by `tools/art_prompts/build_prompts.py` (edit the creature data there and rerun).

## How to use

1. One image = ONE stage. Paste that stage's whole prompt into ChatGPT (image generation).
2. Fix it with the follow-up lines at the bottom of each file until you approve it.
3. Next stage: in the same chat, or a new chat with the approved sheet(s) attached, paste the next stage's whole prompt. Always paste the whole prompt; ChatGPT forgets earlier rules.
4. Put it in the game: save the approved image in its line's folder, named `<id>_gpt...`, e.g.
   `art_src/daemons/02-Pingo/pengwan_gpt_v2.png`, then run
   `godot --headless -s tools/art_import/import_sheet.gd -- --all`.
   It reads 4x4 (16 poses) or 6x2 (12 poses, e.g. 1536x1024; the 4 missing ones are filled from idle) sheets.
   That writes `assets/sprites/daemons/<id>_sheet.png` for every image (4x4 frames of 64x64, background
   removed: magenta, plain, or already transparent) and the battle screen, CMDB, Summary and starter
   picker use it automatically. Tidy it in Aseprite if needed, and log it in the vault's Daemon-Log.
5. Polish it (needs Aseprite + the Aseprite MCP, see the vault's Assets > Tools): from the MCP folder run
   `PYTHONPATH=. uv run python <repo>/tools/art_import/polish_sheet.py <repo>/assets/sprites/daemons/<id>_sheet.png`.
   It cuts the sheet to 15 colors picked from its own pixels (small accents like effect cyan or LED green keep
   a slot) for flat GBA-style shading. A test fails if a sheet has more than 16 colors.

Sheet layout: 1024x1024, invisible 4x4 grid of 256x256 cells, each sprite 64x64 art pixels at 4x. Rows: front poses · front reactions · back view · specials (evolution glow or final-form pose, overheated, throttled, menu icon).

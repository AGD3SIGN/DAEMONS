# Sprite prompts for ChatGPT

Generated by `tools/art_prompts/build_prompts.py` (edit the creature data there and rerun).

## How to use

1. One image = ONE stage. Paste that stage's whole prompt into ChatGPT (image generation).
2. Fix it with the follow-up lines at the bottom of each file until you approve it.
3. Next stage: in the same chat, or a new chat with the approved sheet(s) attached, paste the next stage's whole prompt. Always paste the whole prompt; ChatGPT forgets earlier rules.
4. Save each approved sheet, shrink it in Aseprite (Sprite Size 25%, Nearest Neighbor → 64x64 frames), and log it in the vault's Daemon-Log.

Sheet layout: 1024x1024, invisible 4x4 grid of 256x256 cells, each sprite 64x64 art pixels at 4x. Rows: front poses · front reactions · back view · specials (evolution glow or final-form pose, overheated, throttled, menu icon).
